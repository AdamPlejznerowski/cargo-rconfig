# cargo-rconfig
Cargo subcommand extending Rust's build system with declarative environment and flag management.

## Install
You can install `cargo-rconfig` using `cargo install cargo-rconfig`, or add it as a library to your project with `cargo add cargo-rconfig` or by adding it to your `Cargo.toml`.
